# TaxSavvy - Intelligent Tax Planning & Management System

## Project Overview
TaxSavvy is a comprehensive tax management and planning application developed during a 45-day internship. It helps businesses and individuals optimize their tax planning, manage expenses, and ensure regulatory compliance through AI-powered insights and automated calculations.

## Features
- 🧮 **Intelligent Tax Calculator**: Real-time tax calculations with up-to-date rules
- 📊 **Expense Management**: Track, categorize, and optimize business expenses
- 🤖 **AI-Powered Tax Assistant**: Get personalized tax-saving recommendations
- 📄 **Document Management**: OCR-enabled receipt scanning and organization
- 📈 **Financial Planning**: "What-if" scenarios and salary optimization tools
- 🔄 **ERP Integration**: Seamless sync with existing business systems
- ⚡ **Regulatory Compliance**: Automated compliance checks and reminders
- 📱 **Responsive Interface**: Modern UI built with React and Tailwind CSS

## Tech Stack
### Frontend
- React.js
- Redux Toolkit
- Tailwind CSS
- Vite
- Recharts for visualization

### Backend
- Node.js & Express
- MongoDB
- JWT Authentication
- Tesseract.js for OCR
- Redis for caching
- Google's Gemini AI

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- MongoDB
- Redis (optional)
- npm or yarn

### Installation

1. Clone the repository:
\`\`\`bash
git clone https://github.com/pdonda06/TaxSavvy.git
cd TaxSavvy
\`\`\`

2. Install frontend dependencies:
\`\`\`bash
cd client
npm install
\`\`\`

3. Install backend dependencies:
\`\`\`bash
cd ../server
npm install
\`\`\`

4. Configure environment variables:
- Create .env file in server directory with required variables (see .env.example)

5. Start the development servers:

Frontend:
\`\`\`bash
cd client
npm run dev
\`\`\`

Backend:
\`\`\`bash
cd server
npm run dev
\`\`\`
